# Heil Technical Service Bulletin 2024-009

Subject: HEI961 smart thermostat — Wi-Fi auto-reconnect on router reboot.

Symptom: after a router restart or ISP-side network reset, thermostat does not auto-reconnect to Wi-Fi. HVAC control continues to function locally; remote app does not.

Resolution: firmware update HE-64562. OTA delivery to thermostats with active cloud connectivity; manual USB update for thermostats that have lost connectivity.

Warranty: not warranty-replacement eligible; software-only fix.
